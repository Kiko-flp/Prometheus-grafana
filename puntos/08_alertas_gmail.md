# 8. Alertas por correo electrónico con Gmail

Configuración de notificaciones por correo electrónico en Grafana mediante el servidor SMTP de Gmail.

## 8.1 Parámetros SMTP básicos

| Parámetro | Valor |
| --- | --- |
| **Host** | `smtp.gmail.com:587` |
| **Usuario** | Cuenta de Gmail emisora |
| **Contraseña** | Contraseña de aplicación (*App Password*) |
| **TLS / STARTTLS** | Habilitado |
